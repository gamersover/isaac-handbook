# 以撒道具手册 · Isaac Handbook

本版是可运行的静态前端项目。构建后打开 `dist/index.html`，也可以运行 `npm start` 后访问本地 8080 端口。数据随版本打包，道具图标缓存在 `assets/items` 并随站点部署，原始来源保存在数据的 `iconSource` 字段。

## 功能

- 721 个道具条目（包含 4 个游戏内部隐藏条目），中文、英文、拼音、ID 和效果搜索。
- 31 个道具池目录；道具池、品质和类型可组合筛选。
- 详情展示效果、解锁条件、所在道具池、池内初始权重、相邻道具及 `g c<ID>` 指令。
- 倒转骰子模式不应用图鉴筛选。分为“找目标的来源”和“计算两道具次数”。选择目标后按 ID 递增展示来源条目，标明“此道具 → 目标”的次数，并保留不可达条目的原因。
- 两道具计算：输入当前道具和目标道具，显示方向是否可达以及实际倒转次数。提供交换按钮。
- 收藏与最近查看存于当前浏览器；不连接或修改游戏存档。

## 数据与计算边界

右上角全局切换 **忏悔 1.7.9b** / **忏悔+ 1.9.7.15**，会记住浏览器选择。两个选项代表明确的资料快照，不代表平台上的最新补丁；未纳入 1.9.7.16 及后续更新。切换会同时更新效果搜索、说明、品质、充能、道具池、权重及池内数量，并保留搜索条件、筛选、收藏和最近查看。倒转计算读取当前版本的隐藏标记。

- 忏悔+ 游戏资源镜像：[1.9.7.15.J374](https://github.com/Derugon/TBoIR-resources/tree/1.9.7.15.J374/resources)。使用 `resources`，不使用该分支中遗留的 `resources-dlc3`；原 XML 和校验哈希保存在 `data/sources/repentance-plus`。
- 忏悔游戏资源镜像： https://github.com/Derugon/TBoIR-resources/tree/master/1.7.9b.J835/resources-dlc3
- 原手册元数据、图标： https://github.com/Swashua/Bindings-of-Isaac-Cheat-Sheet
- 中文名、拼音沿用已有项目数据（isaac-chinese-console）。中文效果摘要及解锁条件根据已有英文说明整理，原始字段保留；效果原文可在详情中展开。摘要优先整理原文中适用于忏悔的表述，未进行全部道具的游戏内逐项验证。
- 资源获取日期：2026-09-27。`data/sources` 保留原始 XML，`data/catalog.json` 为合并数据，`src/data.js` 为同一数据的浏览器脚本。
- 忏悔+效果以原有中文摘要为基础，按发行版、1.9.7.9、1.9.7.11、1.9.7.13 官方更新说明整理 50 件道具的主要效果与联动差异，维护于 `data/repentance-plus.json`，每条保留来源链接。未改动的摘要复用基础内容；未进行全部效果及特殊联动的游戏内逐项验证，不宣称是完整的版本差异百科。更新过的效果隐藏旧英文原文，避免正文与原文冲突。完整品质、充能、隐藏标记与道具池则从各版 XML 独立构建，不靠手写补丁猜测。
- 初始权重不等于掉落概率。掉落还受解锁、角色、道具池消耗等机制影响。
- 倒转默认 **全解锁、普通局、无车载电池**；跳过空编号和隐藏条目，不读取实际存档。爸爸的便条 #668 截断向更小 ID 的路线。挑战、每日挑战、特殊模组或其他改变重随行为的机制不在计算范围内。
- 路线列表保留所有后续条目，包括隐藏和被截断的条目，并分别标注原因，不通过过滤制造“全部可达”的误解。

## 项目结构

`src/shell.html` 页面结构；`src/styles.css` 样式；`src/app.js` 交互与计算；`src/select.js` 可搜索、支持键盘的主题下拉选择器；`src/data.js` 数据。
`data/references.json` 维护正文道具引用、Wiki 词条和同名消歧规则。
`data/repentance-plus.json` 维护带更新来源的忏悔+中文效果覆盖；构建时把基础目录与 Plus 快照一起打包到 `data/catalog.json` / `src/data.js`，不在运行时请求远程数据。
`build.py` 生成开发入口 `index.html` 和发布目录 `dist`，包含内联脚本页面、本地图标与托管响应头。

```sh
npm ci
npm run build
npm test
npm start
```

构建只依赖 Python 3；运行网页无需安装 npm 包。`linkedom` 仅用于开发测试。构建时从 `items_metadata.xml` 的 `<item>` 节点同步品质，避免与复用 ID 的 `<trinket>` 节点混淆。`data/zh-cn.json` 覆盖全部 721 个条目：719 条中文效果摘要，2 个缺少原始效果说明的隐藏条目（#59、#656）明确标注资料缺失。全部解锁条件均提供中文；英文效果保留为可折叠原文，原文为空时不显示空的折叠入口。测试校验中文覆盖率及生成数据的一致性，避免新增条目无声退回英文。

## 交互与布局

- 中文说明中的已标注道具名可直接打开站内详情；顶部返回按钮恢复上一件道具的阅读位置和原文展开状态。Boss、角色及机制使用中文 Wiki 外链，在新标签页打开。同名角色、Boss、道具按上下文消歧；常用 Boss 使用实体词条地址，尚未确认固定地址的词汇使用 Wiki 站内查找。普通词语不会仅因与道具同名就自动变为链接。
- 获取方式只保留道具特有来源；“一美元”描述老虎机奖励，不重复列出死亡证明等通用途径。

- 导航和搜索固定，内容区单独滚动。桌面筛选栏吸顶，手机筛选默认收起。
- 详情固定在视口内，仅正文滚动；手机采用全屏详情。打开时锁定背景，关闭后恢复原位置与焦点，支持 Escape 和对话框内 Tab 循环。
- 收藏按钮使用独立区域，支持撤销。图鉴、收藏、最近查看分别保留查询和筛选状态。
- 道具池使用一个专用搜索入口，可切换普通局 / 贪婪模式，并从列表返回目录。
- 筛选条件可逐个清除；空收藏、空记录与无匹配结果分别提供恢复操作。翻页后定位到新结果顶部。
- 倒转候选支持方向键选择；计算器在输入变化后清除旧结果，并标记无效字段。

## 验证

`npm run build && npm test` 执行全部 721 个道具的品质源数据校验，以及 45 组 DOM 交互回归测试，涵盖道具池、组合筛选、分页、倒转边界、收藏撤销、独立栏目状态、详情锁定、中文摘要搜索、下拉选择键盘操作、动画中断及减少动态效果设置；新增版本切换、数据回切、版本偏好持久化、品质与描述筛选、动态池数量和旧计算结果失效验证。

关键算例：D20 #166 → D6 #105 为 61 次；反向不可达；649 → 647 为 1 次；657 → 655 为 1 次；669 → 636 不可达；669 → 668 为 1 次。

本次已在真实浏览器检查桌面及 390×844 手机视图，包括详情独立滚动、背景锁定、关闭位置恢复、翻页定位和手机筛选。道具图标随站点部署，加载失败会显示编号占位；外链 Wiki 未逐一验证。

## Cloudflare Pages 部署

GitHub 仓库：[gamersover/isaac-handbook](https://github.com/gamersover/isaac-handbook)。Pages 项目名为 `isaac-handbook`，默认地址为 [isaac-handbook.pages.dev](https://isaac-handbook.pages.dev/)。

使用 GitHub 集成，生产分支为 `main`，框架预设选择 `None`，构建命令为 `npm run build && npm test`，输出目录为 `dist`。构建依赖 Node.js 和 Python 3，不需要服务器或数据库。每次推送后由 Cloudflare 构建并发布。

`assets/items` 已包含全部道具图标，常规构建无需联网下载。需要重新缓存图标时运行 `python3 scripts/cache_icons.py`。

自定义域名为 [isaac.caoqinping.com](https://isaac.caoqinping.com/)。先在 Pages 中添加自定义域名，再在腾讯云 DNSPod 中为 `isaac` 添加 CNAME，指向 Pages 为项目分配的域名；无需迁移主域名的 DNS。

本项目对应的解析为：主机记录 `isaac`，类型 `CNAME`，记录值 `isaac-handbook.pages.dev`，线路默认，TTL `600` 秒。HTTPS 由 Cloudflare 自动签发与续期，不需要额外上传腾讯云证书。
